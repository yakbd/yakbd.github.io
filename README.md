# yakbd.github.io

The source of the YAKBD website, **https://yakbd.github.io/**: install guides, the editor, the `.kbl.json` format
and the `yakbd` command reference for Windows, macOS and Linux.

Guide pages are written here (`docs/`); reference pages are fetched from the other YAKBD repositories at the
commits pinned in [`sources.json`](sources.json). How to build, re-pin and add a page: [`AGENTS.md`](AGENTS.md).

```sh
npm ci && npm run build
```
